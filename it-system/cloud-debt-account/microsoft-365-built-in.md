# Microsoft 365 built-in

As part of your Cloud Debt account, you have the option to add-in a Microsoft 365 subscription at no additional charge. This gives you access to:

* Full Microsoft Office productivity suite (Word, Excel, PowerPoint, etc.)
* 1TB OneDrive storage
* Custom domain supported Microsoft Outlook mailbox

It's equivalent to a [Microsoft 365 Business Standard](https://www.microsoft.com/en-us/microsoft-365/business/microsoft-365-business-standard) subscription without the Copilot add-on. You may claim this complementary benefits if you really want any of the stuff above.
