# Compute Cluster

The Sheldon Bois Compute Cluster is the powerful server backend used to host the College Debt SMP amongst other stuff.

For security purposes, you will need your College Debt 365 account to access any of the server's web services. The College Debt SMP amongst some exception does not require this.

## Hosting more stuff

In addition to the SMP, you can run additional Minecraft servers or any other game server on the system. This can be done via the Pelican Panel.
