# Cloud Debt account

In making sure that only us can access some of the self-hosted services that has been put out, we have our own SSO authentication system similarly to what you seen at your school and work place.

### Do I need it?

If you do not have any intention to use any other provided services beyond the College Debt SMP and Discord, then you don't have to. We do recommend having one just in case if we ever need everyone to authenticate for security reason.

### Account security

If you forget your password, contact [one of the admins](../get-help.md), and they will give you a temporary password to reset.

For best security practice, we highly recommended that you enable two-factor authentication using a TOTP authenticator app or via a physical FIDO-2 compliant security key. If possible, also have a password manager generate the account password for you.

### Privacy policy

We generally do not collect nor use any traceable data that comes from the usage of your account. Because Cloud Debt accounts are hosted by Microsoft, any legal language or big worded policy are bounded in part by [Microsoft Services Agreement](https://www.microsoft.com/en-us/servicesagreement), but we generally have more legal protections over our data as an enterprise organization.

### Additional features

#### Microsoft Edge

By signing into Microsoft Edge with your Cloud Debt account, you will be presented with a de-bloated and privacy-hardened version of the browser without needing to mess around with OS configurations. It also comes with uBlock origin included amongst other privacy-related extensions.
