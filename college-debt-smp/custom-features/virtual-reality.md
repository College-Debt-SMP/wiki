# Virtual Reality

The server supports Vivecraft with full locomotion support. VR movements are visible to all players with the exception of Bedrock client.

To get started, install the [Vivecraft](https://www.vivecraft.org/) mod and have a compatible VR headset running through SteamVR. For Oculus/Meta Quest users, though untested, you may also use [QuestCraft](https://questcraft.org/).
