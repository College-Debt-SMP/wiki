# Custom features

The server has been modded in a way that expand upon the existing gameplay designs and features of vanilla Minecraft to provide more content while staying true to the look and feel of the base game. Players do not have to install any mods to play on the server unless they want to utilize certain optional features. Refer to the sub-sections in the sidebar to know the custom goodies.
